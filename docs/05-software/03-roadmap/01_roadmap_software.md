# Roadmap y Funcionalidades: Software Hub

Catálogo de ideas, requerimientos completados y objetivos futuros para el **Software Hub** (`software.jorgedoicela.com`).

---

## 1. Módulos y Categorías
- [x] **7 Categorías Temáticas:** Noticias, Blog, Foros, IA, Ciberseguridad, Tutoriales y Proyectos.
- [x] **Barra de Navegación Neumórfica (`CategoryNav`):** Filtros reactivos por categoría.
- [x] **Buscador en Tiempo Real:** Búsqueda instantánea por texto, tags y títulos.
- [ ] **Módulo de Comentarios en Artículos:** Hilos de discusión debajo de cada post.
- [ ] **Editor Markdown Enriquecido:** Soporte para bloques de código interactivos y resaltado de sintaxis.
- [ ] **Sistema de Votos / Reacciones:** Contador interactivo de "me gusta" y aplausos.

---

## 2. Administración y Gestión
- [ ] **Panel de Administración Protegido (`/admin/software`):** Publicación visual de artículos sin tocar la base de datos.
- [ ] **Gestión de Borradores:** Estados `draft` y `published`.
- [ ] **Feed RSS / Atom:** Generación automática de feed XML para lectores de noticias.
- [ ] **Exportación de Artículos a PDF:** Descarga de manuales y tutoriales en PDF formateado.
